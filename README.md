## Development

Static HTML and CSS, with no build step or external runtime dependencies. Preview with `python3 -m http.server 8080` and open `http://localhost:8080`.

GitHub Pages publishes `main` from the repository root. The `Vashisht-Portfolio/` page redirects older portfolio links to the canonical site.
