02Local research prototype

MFlash

Small models that choose useful actions.

A local macOS decision-model prototype that selects from 74 action templates, ranks candidates, and passes typed arguments to controlled adapters.

PyTorch · MPNet · macOS · SQLite

Read design notes

The model routes decisions through four typed adapters: files, retrieval, Apple Notes, and macOS. File operations use authorization, cancellation, receipts, stale-state checks, and reversible undo. Source is not currently public.
